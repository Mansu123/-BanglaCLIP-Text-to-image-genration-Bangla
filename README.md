We developed BanglaCLIP, a vision-language model tailored for Bengali, to address the lack of multimodal resources in low-resource languages. Trained using few-shot learning techniques, BanglaCLIP effectively learns to align Bengali text with corresponding images using limited data. We then integrated BanglaCLIP with a diffusion model to build a Bengali text-to-image generation system, enabling the creation of high-quality and culturally relevant images from Bengali text prompts. This integration combines BanglaCLIP’s semantic understanding of Bengali with the powerful generative capabilities of diffusion models, marking a significant advancement in Bengali text-to-image synthesis and promoting inclusive AI for underrepresented languages.
